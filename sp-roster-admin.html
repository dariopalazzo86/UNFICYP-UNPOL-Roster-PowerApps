roster-shifts.json structure

The file saved to SharePoint contains:

version — schema version
startDate — first day of the 56-day window (ISO date)
shiftDefs — array of working shift definitions
roster — object keyed by user ID (u{SpListItemId}), value is array[56] of shift keys

Leave days from the SP list are not stored in this file — they are always read live from SharePoint.
Bulk actions

These only affect working shifts in the JSON. Leave days from SP are unaffected.
